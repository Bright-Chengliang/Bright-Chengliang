# Chengliang Liu

PhD researcher at [The Hong Kong Polytechnic University](https://www.polyu.edu.hk/), working on **Generative Recommendation (RecAgents), Long-Horizon Agent Memory, and LLM Inference Efficiency**.

My research focuses on how to make LLM and agentic systems scalable, reliable, and cost-efficient over long interaction horizons: investigating latent memory architectures and reinforcement learning for generative recommendation agents, and probing internal representations to improve inference efficiency and adversarial robustness.

## Research Focus

- **Generative Recommendation & RecAgents**: Long-horizon user interaction modeling, scalable agent memory architectures, and decision-making over long interaction sequences.
- **Agent Memory & Reasoning**: Latent memory compression, structured retrieval mechanisms, and reinforcement learning with step-wise feedback signals.
- **Inference Efficiency & Systems**: Representation probing, early-detection proxies, and robustness evaluation across retrieval-augmented generation and tool-using systems.

## Selected Research Highlights

- **Long-Horizon Recommendation Agents** *(In Progress)*  
  Exploring scalable latent memory architectures and reinforcement learning for long-horizon generative recommendation agents.
- **Inference Cost Attacks for Retrieval-Augmented LLMs** *(WWW 2026, CCF-A)*  
  Identified multi-stage computation amplification vulnerabilities in production RAG systems and designed adaptive early-exit mitigation strategies.
- **Representation-Level Probing for Efficient Generation** *(Under Review)*  
  Investigating internal activation dynamics to detect redundant computational loops early in retrieval-augmented generation pipelines.
